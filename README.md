# Training Assessment PR Guidelines

## Submission Rules

1. Create a separate branch for each assessment.
2. Use the branch naming convention: `trainee-name/assessment-name`(eg: aparna/checkpoint-2).
3. Raise a Pull Request against the `main` branch.
4. Use the following PR title format: `[Assessment Name] - [Trainee Name]`.
5. Include a description of the implementation and the requirements completed.
6. Attach screenshots or a demo recording wherever applicable.
7. Include instructions to run and test the solution.
8. Ensure the code follows the assessment requirements and coding standards.
9. Do not include generated files, dependencies, credentials, or unrelated changes.
11. Do not merge your own PR. Only an authorized mentor or evaluator can approve and merge submissions.
